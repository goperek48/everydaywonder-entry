A single sentence (132 characters) for make.fun's "Everyday Wonder, Two Days to Find the Line" bounty ($2, top 2 paid) — one everyday moment made strange and new. An AI judge compares entries two at a time against the published brief.

The entry:

> The lift doors opened on a stranger humming my dead grandmother's lullaby, and for one floor I believed the building remembered her.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline.
